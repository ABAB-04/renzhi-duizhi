# 认知对峙

一款以「识别抬杠话术与逻辑谬误」为核心的回合制文字对战游戏，使用 **Godot 4** 开发。

玩家需要读对手的台词、判断谬误类型、选择接话姿态，在 12 个回合里管理 **理智 / 信念 / 舆论** 三条数值线，走向 12 种不同结局。

## 内容规模

- 12 回合对战、5 种性格、6 个场景、12 种结局
- 11 项成就、18 道谬误识别题、约 1 万字中文文本

## 设计要点

- **消除支配性策略**：「姿态识别 + 押注加码」的 trade-off 结构，让不同性格与路线真实分化，而不是找出一个最优解通关。
- **数据驱动**：全部内容集中在 `core/game_data.gd` 的常量字典里，逻辑代码不写死文案。
- **程序化音频**：用 GDScript 以正弦 / 三角波叠加 + 指数衰减包络合成全部音效与循环 BGM，零外部音频素材，规避版权问题。
- **状态与存档**：基于 Autoload 的全局状态 + 事件驱动，成就持久化，每回合自动存档 / 继续游戏。

## 目录结构

```
core/       # game_data.gd（内容数据）、audio.gd（音频合成）、global_data.gd（全局状态）
scenes/     # 主菜单、性格选择、对战、结局、成就、图鉴、设置
assets/     # 图像、图标、字体
```

## 运行

1. 安装 Godot 4.x；
2. 用 Godot 打开本目录的 `project.godot`；
3. 按 F5 运行。
